# 能层与能级符号

- 学科：化学 / 章节：原子结构
- 状态：新
- 更新：2026-11-24

## 我会怎么错

看到 `2d`、`3f` 这种符号不敢下手，觉得字母就是随便配的；或者只记住「能层越大能量越高」，忘了**第 n 层只有 n 个能级**。

## 正确怎么走

**第一条：能层号 n 决定这一层最多有几级台阶。**

```
n = 1  →  1s
n = 2  →  2s 2p
n = 3  →  3s 3p 3d
n = 4  →  4s 4p 4d 4f
```

规律：从 `s` 开始按 s、p、d、f 顺序数，**第 n 层最多只能数到第 n 个**。

**第二条：字母对应的 l 值。**

```
s → l=0，p → l=1，d → l=2，f → l=3
```

能级存在的条件是 **l < n**。所以 `2d`（l=2，n=2）不成立，`3f`（l=3，n=3）也不成立。

**第三条：别跟能量高低搞混。**

同层内 `ns < np < nd < nf`；跨层会交错，`4s < 3d`，排电子顺序和「符号是否存在」是两件事。

## 典型题

以下能级符号不正确的是（　）

A. 2d　B. 3p　C. 4s　D. 6f

- `3p`：n=3，l=1 < 3 ✔
- `4s`：n=4，l=0 ✔
- `6f`：n=6，l=3 ✔
- `2d`：n=2，l=2，不满足 l < n ✘ → 答案 **A**

## 自测

- 不查表写出 n=1 到 n=4 各自的能级
- 说出 `5g` 存不存在（存在：g 对应 l=4，n=5 时 4 < 5 成立）
- 一眼判出 `1p`、`2d`、`3f` 都是假符号

## 轨道与容量

每个能级里的轨道数：`s → 1`，`p → 3`，`d → 5`，`f → 7`；每条轨道最多 2 个电子。

| 能级 | 轨道数 | 最多电子 |
|---|---|---|
| s | 1 | 2 |
| p | 3 | 6 |
| d | 5 | 10 |
| f | 7 | 14 |

**典型题 2**：某能层上 `nd` 能级最多容纳多少电子？d 有 5 条轨道 → 5×2 = **10**，选 B。层号 n 不影响 d 的容量。
