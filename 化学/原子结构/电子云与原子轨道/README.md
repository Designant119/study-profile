# 电子云与原子轨道

- 学科：化学 / 章节：原子结构
- 状态：新
- 更新：2026-11-24

## 我会怎么错

以为电子像行星一样绕核转圈，把「轨道」当成跑道；把 s 的球形和 p 的哑铃形记混；轨道数 `2l+1` 和电子容量 `2(2l+1)` 混着用。

## 正确怎么走

**第一步：电子云是概率图**

电子没有确定的轨迹，只有「出现的概率」。把小点按概率画出来，点密的地方它常去，这团点叫电子云。点密 ≠ 电子多，是「常出现」。

**第二步：轨道是这团云的形状**

| 能级 | 形状 | 轨道数 |
|---|---|---|
| s | 球形 | 1 |
| p | 哑铃形，px / py / pz 三个方向 | 3 |
| d | 花瓣形 | 5 |
| f | 更复杂 | 7 |

轨道数 = `2l+1`（l = 0,1,2,3 对应 s,p,d,f）。

**第三步：一条轨道两个电子**

泡利原理：每条轨道最多 2 个电子，自旋相反。所以容量 = `2(2l+1)`：s 2、p 6、d 10、f 14。

**第四步：四个量子数（知道分工就行）**

```
n  能层（第几层）
l  能级形状（s p d f）
m  轨道的伸展方向
ms 自旋方向（↑ 或 ↓）
```

## 典型题

`2p` 能级有几条轨道、最多几个电子？

`p` 有 3 条轨道，每条 2 个 → 3 条轨道、6 个电子。

## 自测

- 一句话说清「电子云不等于电子轨迹」
- 说出 s、p、d、f 的形状和轨道数
- 分清「轨道数」和「能装几个电子」
