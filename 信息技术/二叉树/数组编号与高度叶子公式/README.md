# 数组编号与高度叶子公式

- 学科：信息技术 / 章节：二叉树
- 状态：高频
- 更新：2026-11-23

## 我会怎么错

编号记成 i 和 i+1；合上卷公式全空。

## 正确怎么走

- 数组存完全二叉树：左 `2i`、右 `2i+1`、父 `i//2`
- 高度 = log2n 取整 + 1
- 完全树叶子 = n − n//2（前一半干活，后一半是叶）
- 任何树 n0 = n2 + 1（叶子比双孩子多一个）
- 满二叉树节点 = 2 的 h 次方 − 1

忘了就画 7 个节点的小树自己数。

## 典型题

15 个节点的完全二叉树：高度 4 层，叶子 8 个。

## 自测

给 n=15、n=20，20 秒内报高度和叶子数。
