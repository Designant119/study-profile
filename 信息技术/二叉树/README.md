## 我会怎么错

公式一合卷就空；前中后序分不清根在哪；数组编号记成 i 和 i+1。

## 正确怎么走

- 前序 **根左右**、中序 **左根右**、后序 **左右根**
- 前序定根，中序分左右；已知前序加中序可还原整棵树
- 数组存完全二叉树：左 `2i`、右 `2i+1`、父 `i//2`
- 高度 = log2n 取整 + 1
- 完全树叶子 = n − n//2（前一半干活的，后一半是叶）
- 任何树 n0 = n2 + 1（叶子比双孩子多一个）
- 满二叉树节点 = 2 的 h 次方 − 1

忘了就画 7 个节点的小树自己数。

## 典型题

前序 A B D E C F、中序 D B E A F C → 后序 D E B F C A。

15 个节点的完全二叉树：高度 4 层，叶子 8 个。

## 自测

给 n=15、n=20，20 秒内报高度和叶子数；给前序加中序，能写出后序。
