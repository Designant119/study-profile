# 三序遍历与还原

- 学科：信息技术 / 章节：二叉树
- 状态：高频
- 更新：2026-11-23

## 我会怎么错

前中后序分不清根在哪；给前序加中序不会还原。

## 正确怎么走

- 前序 **根左右**、中序 **左根右**、后序 **左右根**。
- 前序第一个就是根；中序里根的左边是左子树、右边是右子树。
- 有前序 + 中序，或后序 + 中序，都能还原整棵树。
- 只有前序 + 后序不行，分不出单孩子长哪边。

## 典型题

前序 A B D E C F、中序 D B E A F C → 后序 D E B F C A。

## 自测

给一棵陌生树，三种遍历都写对；再给前序加中序，能写出后序。
