# 环形队列人数与空位

- 学科：信息技术 / 章节：队列
- 状态：高频
- 更新：2026-11-23

## 我会怎么错

tail 比 head 小时直接相减得负数；人数和空位混。

## 正确怎么走

- 人数 =（tail − head + 容量）% 容量
- 空位 = 容量 − 人数
- **入队动 tail，出队动 head**
- 出队是假删除，只挪 head，数组元素还在
- 跳过某个字符时，head 照样往前走

## 典型题

容量 8、head=5、tail=2 → (2−5+8)%8 = 5 个人，空位 3 个。

## 自测

任意给 head、tail、容量，10 秒内报出人数和空位。
