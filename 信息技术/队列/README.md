# 队列

- 学科：信息技术
- 状态：高频
- 更新：2026-11-23

## 我会怎么错

人数和空位混；环形队列 tail 比 head 小时直接相减得负数；入队出队动错指针。

## 正确怎么走

- 人数 =（tail − head + 容量）% 容量
- 空位 = 容量 − 人数
- **入队动 tail，出队动 head**
- M 操作（出队再入队）= 挪一次，记 1 次
- 优先级队列求最少 M：数前面挡住几个，挡住几个挪几次

## 典型题

容量 8、head=5、tail=2 → (2−5+8)%8 = 5 个人，空位 3 个。

优先级队列 A(3) B(1) C(4) D(2)，最少 M：先挪 A 送 B、再挪 C 送 D，共 2 次。

## 自测

任意给 head、tail、容量，10 秒内报出人数和空位。
