# 优先级队列的M次数

- 学科：信息技术 / 章节：队列
- 状态：高频
- 更新：2026-11-23

## 我会怎么错

把所有元素都算一遍 M，不看谁真的挡路。

## 正确怎么走

- M 操作 = 出队再入队，挪一次记 1 次。
- 求最少 M：看前面挡住几个，挡住几个就挪几次。
- 目标元素前面挡的，必须挪开；已经排好的不用动。

## 典型题

A(3) B(1) C(4) D(2)，求最少 M：先挪 A 送 B、再挪 C 送 D，共 2 次。

## 自测

给一串带优先级的元素，30 秒内报出最少 M 次数。
