# 列表乘法与引用

- 学科：信息技术 / 章节：Python细节
- 状态：中频
- 更新：2026-11-23

## 我会怎么错

`[[0]*3]*3` 以为造了三个独立的行。

## 正确怎么走

- `[[0]*3]*3` 复制的是引用，三行是同一个列表，改一个三行都变。
- 要独立就用 `[[0]*3 for _ in range(3)]`。
- 同理 `a=[0]*3` 没问题，因为元素是数字不可变。

## 典型题

`a=[[0]*3]*3; a[0][0]=1` → 三行第一个都是 1。

## 自测

能解释上面那行为什么三行都变，并写出正确的独立写法。
