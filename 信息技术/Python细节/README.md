## 我会怎么错

切片含头含尾记混；`[[0]*3]*3` 以为造了三个独立列表；range 终点算进去。

## 正确怎么走

- 切片 `s[起:止:步]`：**含起不含止**；负索引从右数，-1 是最后一个；步长 -1 倒着走。
- `[[0]*3]*3` 复制的是引用，三行是同一行；要独立用 `[[0]*3 for _ in range(3)]`。
- `range(a,b,c)`：不含 b。
- `//` 整除、`%` 取余、`**` 乘方。
- 队列代码里 `head += 1` 是假删除，只挪读取起点，不删元素。

## 典型题

`s = "abcdef"`：`s[-1] + s[1:4:2] + s[-2]` → `fbde`。

## 自测

写出 `s[::2]`、`s[::-1]` 的结果，并解释 `a[0][0]=1` 为什么三行都变。
