# 切片边界与负索引

- 学科：信息技术 / 章节：Python细节
- 状态：中频
- 更新：2026-11-23

## 我会怎么错

以为切片含头也含尾；负索引从 0 开始数。

## 正确怎么走

- `s[起:止:步]`：**含起不含止**
- 负索引：-1 是最后一个，-2 是倒数第二
- 步长 -1 倒着走；`s[::-1]` 就是反转
- 步长 2 是隔一个取一个

## 典型题

`"abcdef"`：`s[-1] + s[1:4:2] + s[-2]` → `fbde`。

## 自测

写出 `s[::2]`、`s[1:5]`、`s[::-1]` 的结果，一次不错。
