# 能层能级与光谱

- 学科：物理 / 章节：原子结构
- 状态：新
- 更新：2026-11-24

## 我会怎么错

把「能层」和「能级」混着叫；以为原子能量可以连续变；光谱题分不清发射和吸收；`hν = E_高 − E_低` 里两个下标谁高谁低搞反。

## 正确怎么走

**第一步：分清两个词**

- **能层**：电子待的「壳」，从里往外 `n = 1, 2, 3…`，对应 K、L、M、N 层
- **能级**：每一层里面的「台阶」，同一层还能再分（2s、2p…），台阶高度不一样

一句话：**能层是楼层，能级是楼层里的台阶。**

**第二步：基态和激发态**

- 基态：电子待在最低那个台阶，最稳
- 激发态：吸了能量往上跳，不稳，待不住
- 跳回来就放光子，`hν = E_高 − E_低`

**第三步：光谱怎么分**

- 原子发光 → **发射光谱**，是**线状**的，几条亮线
- 白光穿过原子蒸气 → **吸收光谱**，黑线，位置跟发射线一一对应
- 连续谱来自炽热固体、液体，跟原子能级无关

**第四步：氢原子记一条**

可见光区那几条（巴耳末系）都是跳到 `n = 2` 的落地，别跟赖曼系（落到 `n = 1`，紫外）混。

## 典型题

电子从 `n = 3` 掉到 `n = 2`：放出光子，能量 `hν = E_3 − E_2`，谱线落在可见光区。

反过来，用能量刚好 `E_3 − E_2` 的光子去照基态氢原子，才会被吸收；能量不对，穿过去不吸收。

## 自测

- 能一句话说清能层和能级的区别
- 说得出为什么原子光谱是线状而不是连续
- 拿到「吸收 / 发射」两个字，能立刻判断跃迁方向
