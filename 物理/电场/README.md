# 电场

- 学科：物理
- 状态：高频
- 更新：2026-11-23

## 我会怎么错

单条公式会用，题目一接链条就断；不知道下一步该接运动、能量还是磁场。

## 正确怎么走

1. `F = qE`，匀强里 `E = U/d`
2. `a = qU/(md)`，只由 U、d、q、m 决定，跟初速无关
3. 顺着场飞：`qU = ΔEk`；垂直飞：`t = L/v0`、`y = qUL²/(2mdv0²)`、`tanθ = qUL/(mdv0²)`
4. 接磁场：`qE = qvB → v = E/B`
5. 接电容：闭合看分压 `U = E·R0/(R0+R1)`；断开看电量 `E = Q/(εS)`，只动 d 时 E 不变

判断打不打板：`t1 = L/v0` 与 `t2 = √(2ymax/a)` 比大小。

## 典型题

油滴题：断开开关、下极板下移，E 不变，粒子仍打在 O 点。

## 自测

合上纸，把加速—偏转—打屏整条链默写出来，一个式子不漏。
