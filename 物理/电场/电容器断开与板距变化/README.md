# 电容器断开与板距变化

- 学科：物理 / 章节：电场
- 状态：高频
- 更新：2026-11-23

## 我会怎么错

断开以后还以为电压不变；板距一动就以为 E 也变。

## 正确怎么走

- **开关闭合**：电压 U 由电源定住，动板距 d → `E = U/d` 跟着变。
- **开关断开**：电量 Q 定住，`C = εS/(4πkd)`、`E = Q/(εS)` → **只动 d，E 不变**。
- 断开后 U 会变，因为 `U = Q/C`，C 随 d 变。
- 插介质：C 变大，断开的 Q 不变 → U 变小、E 变小。

## 典型题

油滴悬浮在板间，断开开关后下极板下移：E 不变，油滴受力不变，仍静止。

## 自测

同一道题分别按闭合、断开各算一遍，说清哪个量定、哪个量变。
