# 电场力与运动联动

- 学科：物理 / 章节：电场
- 状态：高频
- 更新：2026-11-23

## 我会怎么错

`F=qE` 会用，题目一接下一步就断，不知道该接运动、能量还是磁场。

## 正确怎么走

1. `F = qE`，匀强场里 `E = U/d`
2. `a = qU/(md)`，只由 U、d、q、m 决定，跟初速无关
3. 顺场飞：`qU = ΔEk`，出射速度 `v = √(2qU/m)`
4. 垂直场飞：`t = L/v0`、`y = qUL²/(2mdv0²)`、`tanθ = qUL/(mdv0²)`
5. 接磁场：`qE = qvB → v = E/B`
6. 判断打不打板：`t1 = L/v0` 与 `t2 = √(2ymax/a)` 比大小

## 典型题

加速后垂直进入偏转场再打屏：先算 v，再算 t，再算 y，最后算偏转角。

## 自测

合上纸默写加速—偏转—打屏整条链，一个式子不漏。
