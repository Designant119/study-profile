## 我会怎么错

直接背，第二天就空；考场上想不起公式，整题放弃。

## 正确怎么走

公式一律配一个小例子，现推：

- 电场链条：一个质子、1000V、2cm 板距，自己代一遍
- 二叉树：画 7 个节点的小树，数高度和叶子
- 圆周运动：`v = ωr`，用转一圈走一圈推
- 磁场：`r = mv/(qB)`，用速度大圈就大记

## 典型题

忘了 `h = v0²/(2g) − M²g/(8Δm²)`，可以从动量定理 `F = 2Δm v` 现推。
