## 我会怎么错

硬背，第二天就空，考场想不起就整题放弃。

## 正确怎么走

每条公式配一个小例子，自己推一遍：

- 电场：一个质子、1000V、2cm 板距，代一遍 `a = qU/(md)`
- 磁场：`r = mv/(qB)`，用「速度大圈就大」记
- 圆周：`v = ωr`，用「转一圈走一圈」推
- 平抛：`h = ½gt²`，用「自由落体叠加匀速」推

## 典型题

忘了 `h = v0²/(2g) − M²g/(8Δm²)`，从动量定理 `F = 2Δm·v` 现推出来。

## 自测

合上书，写出 10 条公式，每条旁边一句「这个式子从哪来」。
