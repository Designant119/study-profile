# 光控电路与电磁继电器

- 学科：物理 / 章节：传感器（选择性必修二 第五章第 3 节）
- 更新：2026-11-25

## 我会怎么错

把"白天灯亮"当常识（路灯本来就是晚上亮）；以为光敏电阻变小就一定让电磁铁变强，忘了干路里还有 $R_1$ 在抢电压；不会算并联支路里谁电流变大。

## 电路长什么样

控制电路：$E$、$S$、$R_1$（干路限流）之后接两条并联支路

- 支路甲：$R_3$ 与电磁铁线圈串联
- 支路乙：光敏电阻 $R_T$ 与 $R_2$ 串联

工作电路：$220\,\mathrm{V}$ 电源、灯泡、继电器触点（常开，吸合才接通）。

## 一步判到底

$$R_T\downarrow \Rightarrow R_{\text{并}}\downarrow \Rightarrow I_{\text{总}}\uparrow \Rightarrow IR_1\uparrow \Rightarrow U=E-I(r+R_1)\downarrow$$

$$\Rightarrow U_{\text{线圈}}\downarrow \Rightarrow I_{\text{线圈}}\downarrow \Rightarrow \text{磁性弱}\Rightarrow \text{衔铁被弹簧拉起}\Rightarrow \text{触点断开}\Rightarrow \text{灯灭}$$

晚上把箭头全部反过来：磁性大，吸合，灯亮。

## 四个选项逐个过

- A：白天光照越强，磁性越强 → 错。越强越弱，电压被 $R_1$ 吃掉了。
- B：白天流过 $R_2$ 的电流大于晚上 → 对。$I_{\text{总}}=I_{\text{线圈}}+I_{R_2}$，总变大、线圈变小，多出来的电流只能从 $R_T+R_2$ 支路走。
- C：白天亮、晚上不亮 → 错。正好反过来。
- D：$P=EI$ 总功率 → 白天 $I$ 大、功率大；D 说晚上大 → 错。

**答案：B**

## 易错点

1. **光敏电阻变小 ≠ 线圈电流变大**，中间隔着 $R_1$ 分压。
2. **电流账本**：$I_{\text{总}}$ 变大而某支路变小，另一支路必然更大。
3. 继电器触点是**常开**：不吸合时灯泡不亮。
