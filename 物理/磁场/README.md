# 磁场

- 学科：物理
- 状态：高频
- 更新：2026-11-23

## 我会怎么错

圆心定不准，图画歪；放缩圆和旋转圆分不清；把周期当成跟速度有关。

## 正确怎么走

- `F = BIL sinθ`，`f = qvB sinθ`，洛伦兹力不做功
- `r = mv/(qB)`，`T = 2πm/(qB)`：半径随速度变，**周期不变**
- 定圆心三步：入射点速度垂线、出射点速度垂线、弦的中垂线
- **放缩圆**：方向定、大小变 → 圆心在同一直线上，找与边界相切
- **旋转圆**：大小定、方向变 → 圆心绕 P 转，能到达范围是半径 2R

## 典型题

速度选择器：`qE = qvB → v = E/B`。

不同速率同方向射入有界磁场、恰好不射出：相切处 `R = d`，反解速度。

## 自测

给「不同速率」和「不同方向」两种描述，立刻说出用哪把工具，并画出临界圆。
