# 圆心与半径周期

- 学科：物理 / 章节：磁场
- 状态：高频
- 更新：2026-11-23

## 我会怎么错

圆心画歪，半径算错；以为速度越大周期越长。

## 正确怎么走

- `r = mv/(qB)`：速度大半径大
- `T = 2πm/(qB)`：**周期跟速度无关**，只跟比荷有关
- `t = (θ/2π)T`，θ 是圆心角
- 定圆心三步：入射点速度的垂线、出射点速度的垂线、弦的中垂线，三选二
- 洛伦兹力不做功，速率、周期都不变

## 典型题

不同速率同方向射入有界磁场，恰好不射出：相切处 `R = d`，反解 v。

## 自测

给入射速度方向和边界，2 分钟内画出圆心和临界半径。
