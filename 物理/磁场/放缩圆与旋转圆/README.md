# 放缩圆与旋转圆

- 学科：物理 / 章节：磁场
- 状态：高频
- 更新：2026-11-23

## 我会怎么错

两种动态圆分不清，题里说「不同速率」却用旋转圆。

## 正确怎么走

**放缩圆**（方向定、大小变）：速度方向固定、速率不同 → 圆心在同一条直线上，半径变化 → 找与边界**相切**的临界圆。

**旋转圆**（大小定、方向变）：速率固定、方向不同 → 圆心绕入射点 P 转 → 粒子能到达的区域是半径为 2R 的圆。

判断口诀：谁变谁就决定圆心怎么动。

## 典型题

同一点、不同方向、同一速率射入：求能打到的边界，答案是以 P 为圆心、2R 为半径的圆。

## 自测

看到「不同速率」和「不同方向」，能立刻说出用哪把工具并画临界图。
