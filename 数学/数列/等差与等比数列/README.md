# 等差与等比数列

- 学科：数学 / 章节：数列
- 状态：新
- 更新：2026-11-24

## 我会怎么错

等比求和直接套公式，忘了先看 `q=1` 这一档；用 `a_n = S_n − S_{n−1}` 时忘了 `n=1` 要单独验；错位相减时项数、符号、最后那项糊成一片。

## 正确怎么走

**第一步：判型**

看到题先问自己：这是等差、等比，还是递推、混合？判型比套公式重要。

**第二步：两套基本公式**

```
等差：a_n = a_1 + (n-1)d
     S_n = n(a_1 + a_n)/2 = n a_1 + n(n-1)d/2

等比：a_n = a_1 q^(n-1)
     q = 1  →  S_n = n a_1
     q ≠ 1  →  S_n = a_1(1 - q^n)/(1 - q)
```

**第三步：求和选方法**

- 纯等差、纯等比 → 直接公式
- 看得到分组 → 分组求和
- 出现分式、根式相减 → 裂项相消
- 等差 × 等比 → 错位相减

**第四步：下标性质**

```
等差：m + n = p + q  ⇒  a_m + a_n = a_p + a_q
等比：m + n = p + q  ⇒  a_m · a_n = a_p · a_q
```

## 典型题

`a_n = 2n − 1`，求前 n 项和。

等差数列，`a_1 = 1`，`a_n = 2n−1`，`S_n = n(1 + 2n−1)/2 = n²`。

## 自测

- 说得出等比求和为什么要先分 `q=1` 和 `q≠1`
- 给一个分式通项，能立刻想到裂项
- 错位相减能写出「原式 − q×原式」的两行对齐
