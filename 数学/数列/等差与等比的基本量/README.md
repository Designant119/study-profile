# 等差与等比的基本量

- 学科：数学 / 章节：数列
- 状态：新（选择性必修二）
- 更新：2026-11-24

## 我会怎么错

等比求和直接套 `S_n = a_1(1−q^n)/(1−q)`，忘了先看 `q` 是不是 1；用 `a_n = S_n − S_{n−1}` 时忘了 `n≥2`，n=1 不单独验；错位相减时项数和符号一乱就全错。

## 正确怎么走

**等差数列**

```
a_n = a_1 + (n-1)d
S_n = n(a_1 + a_n)/2 = n a_1 + n(n-1)d/2
```

**等比数列**

```
a_n = a_1 q^(n-1)
q = 1 时：S_n = n a_1
q ≠ 1 时：S_n = a_1(1 - q^n)/(1 - q) = (a_1 - a_n q)/(1 - q)
```

**三句铁律**

1. 等比求和**先判 q=1**，这一步不写直接扣分。
2. `a_n = S_n − S_{n−1}` 只对 `n≥2` 成立，n=1 必须单独用 `a_1 = S_1` 验。
3. 下标性质：等差 `m+n=p+q ⇒ a_m+a_n=a_p+a_q`；等比是乘积 `a_m·a_n=a_p·a_q`。

**求和四招**：分组求和、裂项相消、错位相减、倒序相加。错位相减是大题常客，最容易死在项数。

## 自测

- 说出等比求和的分类讨论点
- 给一个 `S_n`，能反推 `a_n` 并且验 n=1
- 错位相减能写全，减完的项数对得上
