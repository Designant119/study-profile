# 递推公式与求和方法

- 学科：数学 / 章节：数列
- 状态：新（选择性必修二）
- 更新：2026-11-25

## 我会怎么错

看到 `a_{n+1} = 2a_n + 3` 就想硬猜通项；用 `a_n = S_n − S_{n−1}` 忘了 `n≥2`，n=1 不单独验；裂项相消后剩几项写错；错位相减减完项数对不上。

## 正确怎么走

**第一步：先判型——递推长什么样，决定用哪招**

| 形式 | 招式 |
|---|---|
| `a_{n+1} − a_n = f(n)` | 累加法（逐差相加） |
| `a_{n+1}/a_n = g(n)` | 累乘法（逐项相乘） |
| `a_{n+1} = p·a_n + q` | 构造法：设 `a_{n+1}+t = p(a_n+t)`，`t = q/(p−1)` |
| `a_{n+1} = a_n/(k a_n + 1)` | 取倒数，`1/a_n` 变等差 |

**第二步：S 与 a 的互换（最常考）**

```
n = 1：a_1 = S_1
n ≥ 2：a_n = S_n − S_{n−1}
```

算完必须回头验 n=1，不验就扣分。

**第三步：求和四招**

- 公式法：纯等差、纯等比（等比先判 `q=1`）
- 裂项相消：`1/[n(n+1)] = 1/n − 1/(n+1)`
- 错位相减：等差 × 等比（`S_n − q·S_n` 两行对齐）
- 分组求和：通项能拆成几块分别求

**第四步：两个检查点**

- 裂项后：中间都消了，只剩头尾几项，数清剩几项
- 错位相减后：项数 = 原来项数，符号别丢

## 两个方向互推

**方向一：通项 → 递推（送分方向）**

把 $a_n$ 里的 $n$ 全换成 $n+1$，然后作差或作商：

$$a_{n+1}-a_n=\text{常数}\quad\text{或}\quad \frac{a_{n+1}}{a_n}=\text{常数}$$

例：$a_n=2n+1$ ⇒ $a_{n+1}-a_n=2$；$a_n=3^{n-1}$ ⇒ $\dfrac{a_{n+1}}{a_n}=3$。

**方向二：递推 → 通项（要动手）**

就是上文四招：累加、累乘、构造、取倒数。判型的依据是递推式的形状，不是运气。

任何一条算完，都把 $n=1$ 代进去验一遍。

## 典型题

`a_1 = 1`，`a_{n+1} = a_n + 2n`，求 `a_n`。

累加法：`a_n = a_1 + Σ(2k) = 1 + n(n−1)`（k 从 1 到 n−1）。

## 自测

- 看到三种递推形式，能立刻说出用哪招
- 给一个 `S_n`，能反推 `a_n` 并验 n=1
- 裂项、错位各写一遍，项数对得上
