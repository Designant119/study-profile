# 轨迹题写范围

- 学科：数学 / 章节：解析几何
- 状态：保持（相对稳）
- 更新：2026-11-23

## 我会怎么错

把轨迹写成一整个圆或整条直线，忘了参数只在某区间动。

## 正确怎么走

- 设点 → 联立 → 韦达 → 消参 → **检验范围**
- 范围来自：判别式大于 0、交点存在、参数本身的条件
- 答案写成「曲线 + 括号里的范围」

## 典型题

圆 C₁ (x−3)²+y²=4，过原点的动直线交圆于 A、B，中点 M 的轨迹：(x−3/2)²+y²=9/4，x∈(5/3,3]。

## 自测

同类题 20 分钟内做完，范围不漏写。
