# 独立与互斥别混

- 学科：数学 / 章节：概率
- 状态：新
- 更新：2026-11-23

## 我会怎么错

把互斥当独立：`P(AB)=P(A)P(B)` 到处用。

## 正确怎么走

- **互斥**：不能同时发生，`P(A∪B) = P(A) + P(B)`
- **独立**：互不影响，`P(AB) = P(A)P(B)`
- 互斥且概率都大于 0 → 一定不独立
- 恰好一个：甲中乙不中 + 乙中甲不中

## 典型题

甲乙独立各 0.8，恰好一人中：`0.8×0.2 + 0.2×0.8 = 0.32`。

## 自测

能举出一个互斥不独立的例子，并说清为什么。
