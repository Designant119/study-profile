# 概率

- 学科：数学
- 状态：新
- 更新：2026-11-23

## 我会怎么错

至少一人直接相加；把互斥和独立混成一个概念。

## 正确怎么走

- 互斥（不能同时发生）→ 相加
- 独立（互不影响）→ 相乘
- **至少、至多、不全，一律走对立事件**：`P = 1 − P(全都不)`
- 恰好一个：甲中乙不中 + 乙中甲不中

| 题里怎么说 | 怎么翻 |
|---|---|
| 至少有一个 | 1 − 全都没有 |
| 至多有一个 | 全没有 + 恰好一个 |
| 恰好一个 | 甲中乙不中 + 乙中甲不中 |

## 典型题

甲、乙命中率各 0.9，独立，至少一人中：`1 − 0.1×0.1 = 0.99`。

## 自测

独立、各 0.8：至少一人 30 秒内报 0.96；恰好一人报 0.32。
