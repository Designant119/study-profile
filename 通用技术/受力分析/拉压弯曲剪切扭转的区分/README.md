# 拉压弯曲剪切扭转的区分

- 学科：通用技术 / 章节：受力分析
- 状态：高频
- 更新：2026-11-23

## 我会怎么错

看见零件名字就猜受力：螺栓当剪切、连杆当受拉，不追力是怎么走的。

## 正确怎么走

1. 先找杆件两端受的是什么力。
2. 两端被往中间挤 → **受压**；被往外拽 → **受拉**。
3. 横向力压中间、杆鼓出去 → **受弯曲**（手柄、压杆、跳板）。
4. 两个截面错开 → **受剪切**。
5. 绕轴心转 → **受扭转**。
6. 细长杆受压时，再加一个**弯曲**。

## 典型题

- 压紧机构：手柄受弯曲，连杆受压，物体被压紧。
- 漫步机连杆：人被往下压，连杆被两头夹 → 受压 + 受弯曲。
- 细长支撑杆：受压 + 受弯曲。

## 自测

随手五个机构，能说清谁被顶、谁被拉、谁在弯，并解释得出口。
