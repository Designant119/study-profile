# 螺栓与连杆的受力

- 学科：通用技术 / 章节：受力分析
- 状态：高频
- 更新：2026-11-23

## 我会怎么错

一看到螺栓就选剪切；一看到连杆就选受拉。

## 正确怎么走

**螺栓**

- 轴线垂直于板面、靠拧紧把两块板夹住 → **受拉**。
- 两块板被横向搓动、截面错开 → **受剪切**。

**连杆**

- 两端被顶着（推出去顶住）→ **受压**。
- 两端被拉着（拉回来拽住）→ **受拉**。
- 连杆绕支点转、只传横向推力 → 相切在支点外侧受压，在支点内侧受拉。
- 细长 → 受压时再加**弯曲**。

## 典型题

螺栓夹紧钢板那道：问螺栓受什么力，答案是**受拉**，不是受剪切。

## 自测

给螺栓、连杆各一个情境，能说出受力形式并说明力的方向。
