# 受力分析

- 学科：通用技术
- 状态：高频
- 更新：2026-11-23

## 我会怎么错

先认零件，再猜受力。看见螺栓就想剪切，看见连杆就想受拉，不追力是怎么走的。

## 正确怎么走

1. 找出这根杆件两端受的是什么力。
2. 两端被往中间挤 → **受压**；被往外拽 → **受拉**。
3. 横向力压中间、鼓出去 → **受弯曲**（手柄、压杆、跳板这类）。
4. 两个截面错开 → **受剪切**。
5. 绕轴心转 → **受扭转**。
6. 细长杆受压，再加一个**弯曲**。

螺栓补充：轴线垂直于板面、靠拧紧夹住 → 受拉；被两块板横向搓 → 受剪切。

## 典型题

- 压紧机构：手柄受弯曲，连杆受压，物体被压紧。
- 漫步机连杆：人被往下压，连杆被两头夹 → 受压 + 受弯曲。
- 螺栓夹紧钢板：受拉，不是剪切。

## 自测

给五个不同机构，能逐一说清谁被顶、谁被拉、谁在弯，并且解释得出口。
