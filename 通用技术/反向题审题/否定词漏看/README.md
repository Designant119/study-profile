# 否定词漏看

- 学科：通用技术 / 章节：反向题审题
- 状态：高频
- 更新：2026-11-23

## 我会怎么错

题干里的「不正确」「除外」「不恰当」扫一眼就过去，按正向题做。

## 正确怎么走

1. 第一遍读题就把否定词圈出来。
2. 四个选项逐个判真假，别只看自己觉得对的那个。
3. 选完回头看一眼圈，确认选的是错的那个。

## 典型题

机械手那道「下列分析中不正确的是」，D 说连杆受压，实际连杆受拉。

## 自测

连续 5 道反向题不错，且能说清每个选项错在哪。
