# 工具分类

- 学科：通用技术
- 状态：中频
- 更新：2026-11-23

## 我会怎么错

把金工工具塞进木工题里，比如画线时写上样冲。

## 正确怎么走

按它打出或切出什么来记：

- **样冲**：金属上打样冲眼，给钻头定位。名字来源就是打样眼的冲子。
- **划针、划规、角尺、木工铅笔、钢直尺**：木工画线那一套。
- **锉刀**：修边去毛刺；**锯**：分料。
- **钻孔、攻丝**：金属上做孔和螺纹。

## 典型题

木工画线工具一题，选项里混进样冲，这就是错的那个。

## 自测

给十个工具名，能分成金工、木工、通用三类，并各说一句用途。
