# 木工与金工标准流程

- 学科：通用技术 / 章节：加工流程
- 状态：高频
- 更新：2026-11-23

## 我会怎么错

金工流程套到木工题上，或木工流程漏掉刨削。

## 正确怎么走

**木工小件**：刨削 → 画线 → 钻孔 → 锯割 → 凿削 → 锉削 → 表面处理。

**金工**：划线（先打样冲眼）→ 锯割 → 锉削 → 钻孔 → 攻丝 → 倒角去毛刺 → 表面处理。

要点：先刨后画、先钻后锯、凿完再锉、表面处理收尾。

## 典型题

木工零件流程题：漏了刨削和钻孔的 A、漏了刨削和凿削的 B、漏了钻孔和凿削的 D 都错，C 全。

## 自测

不看笔记默写两套流程，顺序一个字不差。
