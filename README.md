# study-profile

个人学习弱点清单。跨设备、跨账号用来对齐"我到底弱在哪"。

## 里面有什么

- `学习弱点清单.md`：按学科分条的知识弱点，每条写"错法 / 修正 / 验证"。
- `README.md`：本文件，说明用法。

## 用法

1. 考前复习：只看弱点清单，一条条过，能通过"验证"的划掉。
2. 考完复盘：只把"第二次犯"的错加进去，不堆流水账。
3. 换账号：把新账号加成协作者，或用下文方式直接 clone。

## 怎么访问

私有库，需要凭据：

```bash
git clone https://<PAT>@github.com/Designant119/study-profile.git
```

或者直接网页看：https://github.com/Designant119/study-profile

## 说明

- 库是私有的，别人看不到内容；换账号需要先被邀请为 collaborator，或把库转过去。
- 需要公开只读的话，跟我说一声，我改成 public。
