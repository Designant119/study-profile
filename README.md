# study-profile · 学习弱点树

按 **学科 → 章节 → 易错点** 三层放的弱点库。每个易错点是一个文件夹，里面一份说明：怎么错、正确怎么走、典型题、自测。

## 目录树

```
study-profile/
├── 通用技术/
│   ├── 受力分析/
│   ├── 加工流程/
│   ├── 反向题审题/
│   └── 工具分类/
├── 信息技术/
│   ├── 队列/
│   ├── 二叉树/
│   └── Python细节/
├── 物理/
│   ├── 电场/
│   ├── 磁场/
│   └── 公式记忆/
└── 数学/
    ├── 概率/
    └── 解析几何/
```

## 怎么用

1. **复习**：打开对应学科文件夹，按章节过；一个易错点能通过它自己的自测就算过关。
2. **新增**：只加第二次犯的错。在对应章节下新建文件夹，名字就是那个知识点。
3. **更新**：每次考完由陪练直接往这里改，网页刷新就是最新。

## 每个易错点的写法（固定四段）

- **我会怎么错**：具体写成什么样的错误动作，不写粗心这种空话。
- **正确怎么走**：一步一步，能照着做。
- **典型题**：一道原题或同类题。
- **自测**：一条可验证的标准，做到就算过。
