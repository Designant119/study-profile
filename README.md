## 先看哪

- [等级表：谁 Lv1、谁 Lv4](等级表.md) —— 全员 Lv1 起步，只升不降、只增不删

## 怎么用

1. **复习**：学科 → 章节 → 易错点，一层层点下去，每个易错点做完自测才算过。
2. **新增**：只记第二次犯的错。在对应章节下新建一个文件夹，名字就是那个错。
3. **更新**：每次考完由陪练直接改，刷新页面就是最新。

## 目录规则

- 第三层永远是一个**知识点一个文件夹**，不散放文件。
- 每个知识点文件夹里：`README.md` 是知识本体。
- `错题记录.md`：记做错的，谁都有。
- `举一反三做题记录.md`：只记做对的变式和举一反三，**有才建，不是每格都配**。
- 知识点只增不删；错题只追加不改写。
- 原题截图就存**同一个知识点文件夹**里，命名 `原题-序号-说明.png`，README 里用相对链接挂出来。

## 每个易错点固定四段

- **我会怎么错**：具体的错误动作，不写粗心。
- **正确怎么走**：能照着做的步骤。
- **典型题**：一道原题或同类题。
- **自测**：可验证的标准。
